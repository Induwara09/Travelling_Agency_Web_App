# Image credits and usage notes

The primary local visuals were generated specifically for this academic project.
They contain no copied travel-company branding, text or watermarks:

- `hero-sigiriya-v2.webp` — cinematic traveller and Sigiriya landscape
- `tea-train.webp` — blue train through Sri Lankan tea country
- `wildlife-elephants.webp` — ethical wildlife landscape with elephants
- `coast-sunset.webp` — palm-lined southern coast at sunset
- `galle-heritage.webp` — Galle lighthouse and heritage ramparts
- `sri-lanka-hero.webp` — original V1 travel hero retained for compatibility
- `sl-map.webp` — generated illustrated Sri Lanka destination road map

The V3 destination seed uses curated Wikimedia Commons redirect URLs and stores
the matching `imageSourceUrl` file page for attribution/license review. The
catalogue only stores a remote URL when it was confirmed for that exact place.
For other records, the frontend searches Wikimedia Commons using the exact
destination name and district, limits concurrent requests, caches the result
for the browser session and falls back to bundled local imagery when no suitable
result is available. Major-place sources include:

specific license and attribution requirements. Administrators should only add
a replacement image URL when they have permission to use it.
