# Image credits and usage notes

The two primary visual assets included locally in `src/assets/` were generated
specifically for this project and contain no hotel branding:

- `sri-lanka-hero.webp`
- `luxury-eco-resort.webp`

The optional MySQL demo data uses Wikimedia Commons file redirects for Ella,
Sigiriya, Galle and Mirissa. Their file pages and licences are:

- Nine Arches Bridge in Ella — Knthabrew, CC BY-SA 4.0:
  https://commons.wikimedia.org/wiki/File:Nine_Arches_Bridge_in_Ella.jpg
- Sigiriya Sri Lanka — Wikimedia Commons file page:
  https://commons.wikimedia.org/wiki/File:Sigiriya_Sri_Lanka.jpg
- Galle Dutch Fort, Sri Lanka — Wikimedia Commons file page:
  https://commons.wikimedia.org/wiki/File:Galle_Dutch_Fort,_Sri_Lanka.jpg
- Mirissa Beach Sri Lanka — Tharakaliyanage, Wikimedia Commons file page:
  https://commons.wikimedia.org/wiki/File:Mirissa_Beach_Sri_Lanka.jpg

Hotel photographs from official hotel websites are not copied into this
project. An administrator may add an image URL only when they have permission
to use it. The generated local resort image is the default fallback.
