# Image credits and usage notes

The primary local visuals were generated specifically for this academic project.
They contain no copied travel-company branding, text or watermarks:

- `hero-sigiriya-v2.webp` — cinematic traveller and Sigiriya landscape
- `tea-train.webp` — blue train through Sri Lankan tea country
- `wildlife-elephants.webp` — ethical wildlife landscape with elephants
- `coast-sunset.webp` — palm-lined southern coast at sunset
- `galle-heritage.webp` — Galle lighthouse and heritage ramparts
- `luxury-eco-resort.webp` — unbranded nature-integrated resort fallback
- `sri-lanka-hero.webp` — original V1 travel hero retained for compatibility

The optional SQL seed records contain Wikimedia Commons redirect URLs for Ella,
Sigiriya, Galle and Mirissa. Check each linked file page before production use:

- https://commons.wikimedia.org/wiki/File:Nine_Arches_Bridge_in_Ella.jpg
- https://commons.wikimedia.org/wiki/File:Sigiriya_Sri_Lanka.jpg
- https://commons.wikimedia.org/wiki/File:Galle_Dutch_Fort,_Sri_Lanka.jpg
- https://commons.wikimedia.org/wiki/File:Mirissa_Beach_Sri_Lanka.jpg

Official hotel photographs are not copied. Administrators should only add a
hotel or experience image URL when they have permission to use it. See
`VECTEEZY_IMAGE_GUIDE.md` for the optional licensed-replacement workflow.
